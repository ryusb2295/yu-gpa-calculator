# 영남대학교 전공 평점 자동 계산기 (YU GPA Calculator)

영남대학교 URP 성적을 바탕으로 전체·전공 평점과 학년별 이수 현황을 확인하는 비공식 계산기입니다.

## 주요 기능

1. URP 성적조회 표 자동 수집 시도, 성적표 텍스트 붙여넣기, 직접 입력
2. 자동 수집한 URP의 `년도/학기별 누적 성적조회`와 `이수구분별 취득학점` 표시
3. 전체·전공 평점과 편입 후 학년별 이수 현황 분석
4. 과목 학점·성적·전공 여부 수정 및 목표 전공 평점 계산
5. Excel·텍스트 요약 다운로드, JSON 백업·불러오기

GitHub Pages에서는 붙여넣기·직접 입력·계산·내보내기가 브라우저에서 작동합니다. URP 자동 수집에는 별도로 실행한 FastAPI·Playwright 백엔드가 필요합니다.

## 사용 방법

- **자동 수집:** 로컬 백엔드를 실행하고 페이지의 `성적 자동 수집 시작`을 누릅니다. 포털 로그인이나 성적조회 화면 이동이 자동으로 끝나지 않으면 열린 브라우저에서 직접 완료합니다. 자동 탐색에 실패하면 `고급 선택자 설정`의 성적조회 URL을 지정할 수 있습니다.
- **붙여넣기:** URP 성적조회 표를 복사해 `붙여넣기` 탭에 넣고 `성적 반영`을 누릅니다.
- **직접 입력:** 수강연도·학기·과목명·학점·성적·이수구분을 입력합니다. 편입생은 `시작 학년`과 `시작 연도`를 확인하세요.
- **결과 확인:** 자동 수집에서 찾은 URP 요약표는 `URP 성적 조회 결과`에 표시됩니다. 계산기의 평점과 과목별 이수구분은 아래 표에서 검토하고 수정할 수 있습니다.

자동 수집은 포털 화면 구조에 따라 실패할 수 있습니다. 붙여넣기와 직접 입력은 백엔드 없이 사용할 수 있습니다.

## 로컬 백엔드 실행

PowerShell에서 프로젝트 폴더로 이동해 실행합니다.

```powershell
cd C:\Projects\yu-gpa-calculator
python -m pip install -r requirements.txt
python -m playwright install chromium
python -m uvicorn app:app --host 127.0.0.1 --port 8000
```

브라우저에서 `http://127.0.0.1:8000`을 엽니다. 명령은 `app.py`가 있는 프로젝트 폴더에서 실행해야 합니다. 가상환경을 사용하는 경우에는 먼저 가상환경을 활성화한 뒤 같은 명령을 실행하세요.

## 계산 기준

- 자동 수집 시 URP 요약표의 원본 수치를 별도로 표시합니다. 편입인정학점을 제외한 과목별 취득학점 합계가 URP의 전공 취득학점 합계와 같을 때만 해당 과목을 전공으로 확인합니다. 이 방식으로도 개별 과목이 전공핵심인지 전공선택인지는 구별할 수 없습니다.
- 영남대 성적표에서 이수구분을 읽으면 그 값을 사용합니다. 이수구분이 없는 평점 과목은 위 합계로 확인되지 않으면 전공으로 **추정**하며, 과목 목록에서 전공 여부를 수정할 수 있습니다. 추정값은 학교의 공식 이수구분이 아닙니다.
- 계산한 평점은 URP 표시에 맞춰 소수 셋째 자리부터 버리고 소수 둘째 자리까지 표시합니다.
- 편입인정학점은 누적 성적표에 나타날 수 있지만 평점 계산에서는 제외합니다. [영남대 편입학생학점인정 안내](https://ict.yu.ac.kr/main/bachelor/transfer-student-credit.do)
- 과목 목록에서 편입인정학점은 `편입인정`으로, 교양 과목은 `교양`으로 표시합니다. 영남대에서 실제로 수강한 교양은 전체 평점에만 반영하고 전공 평점에서는 제외합니다. 편입인정학점 총합만으로 교양 인정학점을 알 수는 없습니다.
- 학년별 분석은 편입 인정 학점의 연도를 시작 연도로 잡아 3학년·4학년을 표시합니다. 시작 연도가 다르면 화면에서 직접 바꿀 수 있습니다. 편입 이전 성적과 편입 인정 학점은 별도 묶음으로 표시합니다.
- 영남대는 전부(과)·부복수전공 등에 따라 이수구분이 변동될 수 있다고 안내합니다. 최종 이수구분은 URP에서 확인하세요. [영남대 성적관리 안내](https://www.yu.ac.kr/main/bachelor/grade.do)

- 4.5 만점 기준: A+ 4.5, A/A0 4.0, B+ 3.5, B/B0 3.0, C+ 2.5, C/C0 2.0, D+ 1.5, D/D0 1.0, F 0.0
- P·NP와 편입인정학점은 평점 계산에서 제외
- 기본 종합성적 기준에서는 F를 취득학점과 평점 계산에서 제외합니다. 학기성적 기준을 선택하면 F를 0점으로 평점 계산에 포함합니다. [영남대 성적관리 안내](https://www.yu.ac.kr/main/bachelor/grade.do)
- 재수강·소멸 과목은 학교 표시를 확인한 뒤 사용자가 결과를 검토해야 합니다.

JSON 백업은 과목 목록을 저장합니다. 자동 수집한 URP 요약표는 JSON 백업에 포함되지 않습니다.

비공식 보조 도구이며 학교의 공식 성적표나 졸업사정을 대체하지 않습니다.
