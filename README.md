# 영남대 전공 평점 계산기

브라우저에서 성적표를 붙여넣고 전공·전체 평점을 계산하는 비공식 도구입니다.
개인 성적 예제는 포함하지 않습니다. 입력 데이터는 서버로 전송하지 않습니다.

## GitHub Pages 배포
1. GitHub에서 yu_major_credit 저장소를 만듭니다.
2. 이 폴더 안 파일들을 저장소 루트에 업로드합니다. ZIP 자체를 업로드하지 마세요.
3. Settings → Pages → Deploy from a branch → main / (root) → Save.
4. 배포 완료 후 GitHub가 표시하는 사이트 주소를 엽니다.

## 기능과 제한
- 성적표 텍스트 붙여넣기, 과목 직접 추가·수정, CSV 및 TXT 내보내기
- 전공핵심·전공선택·전공필수 전공 집계, 편입인정학점 분리
- P·NP는 평점에서 제외, F는 0점으로 평점에 포함
- 재수강 전·소멸 과목은 계산 반영 체크를 확인해야 합니다.
- 학교 공식 규정 전체를 구현한 졸업사정 도구가 아닙니다.
- 자동 로그인·성적 수집 및 XLSX 내보내기는 미구현입니다.
- 새로고침하면 입력 내용이 사라집니다.
